CASE STUDY 05 / SOFTWARE ARCHITECTURE · FULL-STACK DEVELOPMENT

DataBerry — Gmail Finance Manager

A multi-implementation software initiative exploring ways to centralize financial information received through Gmail and make related records easier to search, review and export.

TechnologyReact · TypeScript · Vite · Node.js · Express · PostgreSQL · Drizzle ORM
Project statusAdvanced development and architecture exploration · Cloud deployment unsuccessful

The challenge

Financial information arrives through email in different formats and across multiple conversations. The project explores how this information can be centralized and organized so users can locate relevant messages, manage related documents, review structured records and export data through a unified interface.

Functional scope

Across documented application designs, the intended scope includes financial email search and organization, document management, dashboard and monitoring interfaces, user settings, structured data storage, CSV export and integrations with Gmail and related Google services. Feature availability and maturity vary by implementation; this list is not a claim that every feature is operational in the latest repository.

Reference architecture

The latest reference repository documents a React/TypeScript/Vite front end, a Node.js/Express back end and PostgreSQL for relational data. Drizzle ORM provides the data-access layer; Tailwind CSS and shadcn/ui support the interface. Google Cloud Run was the target hosting environment, with Google Cloud Build in the build pipeline.

Architecture exploration

Approximately fifteen repositories explored different approaches, technology stacks and environments; they represent variants within one initiative, not fifteen separate portfolio projects. Replit-based implementations had functioning front ends, with potentially minor back-end issues based on the developer’s experience.

Development status and limits

The latest reference repository was not successfully deployed to Google Cloud because repeated Google Cloud Build failures prevented completion. The cause has not been established. Available screenshots show interface design and navigation, but visible metrics are demonstration data, not verified operational results. The documentation does not establish that all features work end to end or that the application entered production on Google Cloud.

Skills demonstrated

Key takeaway

The project demonstrates architecture exploration and full-stack problem-solving while clearly distinguishing implemented interfaces from an unvalidated end-to-end product.
